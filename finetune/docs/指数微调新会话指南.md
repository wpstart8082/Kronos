## 2. 推荐方案：从股票微调版继续训练（迁移微调）

14 个指数的样本量太小，从原始 Kronos-base 直接微调容易欠拟合/过拟合两难；
股票微调版已学会 A 股日线分布（涨跌停缺口、量价结构），继续微调到指数是
数据效率最高的路径。**对照组**用零样本原版（必做）+ 股票微调版（可选）在同一
指数测试集上回测，量化「指数微调」的增量。

## 5. 判读与风险

- **成功标准**：`index_v1` 的信号（尤其 `max`）在指数回测中超额收益优于两个对照组；
  predictor val loss 应低于股票版在指数数据上的水平（说明学到了指数分布）。
- **过拟合信号**：val loss 先降后升且 best 停在很早的 epoch → 降 epochs 或再降 LR。
- **灾难遗忘**：微调后若股票预测明显劣化，属预期权衡；可按需保留两套 checkpoint
  （目录已隔离，互不覆盖）。
- **进阶（可选）**：股票+指数混合回放训练防遗忘——把两份 `train_data.pkl` 的 dict
  合并（股票下采样到 ~10:1）后再 pickle，`dataset.py` 无需改动。本指南先不做。
